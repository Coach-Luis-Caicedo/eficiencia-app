Flujo de trabajo

Cómo usar los instrumentos

1

Distribuir enlace

El consultor envía el enlace a los empleados. Funciona en cualquier dispositivo.

2

Respondentes completan

Cada empleado responde (~8 min / ~1 min). Al finalizar se genera un archivo JSON.

3

Entregar JSON

El empleado envía el JSON al consultor por correo. Los datos nunca suben al servidor.

4

Consolidar en Workbook

El consultor importa los JSON. El Workbook calcula el IIE y genera el tablero ejecutivo.

Guía rápida

Instrucciones para el consultor

Referencia de uso para cada instrumento.

Cuestionario ICE/IEHS

  1. Genera el enlace con el nombre de la organización
  2. Distribuye por correo a todos los respondentes
  3. Cada respondente descarga su JSON individual
  4. Importa en Workbook: Modo admin → Importar cuestionario
  5. El Workbook consolida ICE e IEHS automáticamente

Sensor Diario SD-MO

  1. Distribuye el enlace 3 veces por semana
  2. Cada jornada genera un JSON de jornada
  3. Importa cada jornada: Importar SD-MO
  4. El Workbook calcula el IAO con ventana λ=0.80
  5. Con 4+ jornadas tienes señal estable del IAO

Workbook — motor analítico

  1. Abre el Workbook en este dispositivo
  2. Importa los consolidados del cuestionario y SD-MO
  3. Configura el PIIO con los KPIs operativos
  4. Ingresa N empleados y CIE
  5. El tablero calcula IIE, DEP, impacto $, VRI y T_rec

Privacidad y datos

  1. Los JSON nunca se suben a ningún servidor
  2. Todo el procesamiento ocurre en el navegador
  3. Guarda los JSON en carpeta segura por organización
  4. El Workbook no almacena datos entre sesiones
  5. Informa a respondentes antes de aplicar (habeas data)
