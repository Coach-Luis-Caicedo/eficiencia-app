Guía rápida

Instrucciones para el consultor

Referencia de uso para cada instrumento.

Cuestionario ICE/IEH

  1. Genera un código de invitación individual por empleado
  2. Comparte el código, o el enlace directo con el código incluido
  3. El empleado responde y envía directamente — sin JSON
  4. Las 25 preguntas (5 pares) quedan asociadas a su organización
  5. Un mismo código sirve también para el SD-MO

Sensor Diario SD-MO

  1. Comparte el mismo código de invitación, 3 veces por semana
  2. Cada jornada son 4 preguntas bipolares (~30 seg)
  3. Se envía directamente al completar — sin JSON
  4. Queda asociada a la organización con la fecha de esa jornada
  5. Más jornadas registradas dan una señal más estable del IAO

Workbook — motor analítico

  1. Abre el Workbook en este dispositivo
  2. Importa los consolidados del cuestionario y SD-MO
  3. Configura el PIIO con los KPIs operativos
  4. Ingresa N empleados y CIE
  5. El tablero calcula los índices del sistema, impacto económico y plan de intervención

Privacidad y datos

  1. Las respuestas se envían de forma directa y cifrada, asociadas solo a un código de invitación — nunca a un nombre
  2. El sistema nunca reporta resultados a nivel individual
  3. Los reportes agregados requieren un mínimo de respondentes por grupo
  4. El acceso del consultor está limitado a las organizaciones vinculadas a su cuenta
  5. Informa a respondentes antes de aplicar (habeas data)
